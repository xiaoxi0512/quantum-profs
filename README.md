# 国内高校量子计算课题组教授信息汇总

一个纯静态（HTML + CSS + JavaScript）的检索网站，汇总国内 39 所高校 ~74 位从事量子计算研究的教授及其课题组信息，支持多级展开卡片、标签筛选、关键词搜索，以及每日 08:00 自动更新数据。

## 功能特性

- **多级可展开卡片**：一级显示教授摘要；点击展开二级（简介、联系方式、成果、超链接、企业信息、课题组成员）；再点击成员展开三级详情。
- **多维度筛选**：按技术路线（超导 / 半导体 / 离子阱 / 光量子 / 中性原子 / 拓扑 / 理论算法）与商业应用领域（材料化学、生物医药、金融科技、网络安全、气象预测、信息加密、优化问题、人工智能、材料科学、交通物流）筛选。
- **关键词搜索**：按姓名 / 院校 / 研究方向实时过滤。
- **院校分层排序**：985/C9 → 211 → 中科院 → 普通本科，由高到低排列。
- **每日自动更新**：通过 WorkBuddy 自动化任务每天 08:00 检索官方来源并增量更新数据。
- **联系方式齐全**：每位教授均含官方邮箱与电话（缺失时回退至院系官方联系方式）。

## 文件结构

```
quantum-profs/
├── index.html        # 入口页面
├── version.json      # 轻量版本标记，供前端自动检查更新
├── css/
│   └── style.css     # 多级卡片与筛选栏样式
└── js/
    ├── data.js       # 教授数据库（含 DATA_META 版本元信息）
    └── app.js        # 渲染 / 筛选 / 搜索 / 自动更新逻辑
```

## 本地预览

无需构建，直接双击 `index.html` 即可。如需本地服务器（开启自动更新检查）：

```bash
cd quantum-profs
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 部署到 GitHub Pages

1. 将本项目推送到 GitHub 仓库（例如 `quantum-profs`）。
2. 仓库 Settings → Pages → Source 选择 **main** 分支、**/ (root)** 目录 → Save。
3. 几分钟后访问 `https://<你的用户名>.github.io/quantum-profs/`。

> 注意：自动更新检查依赖前端定时 `fetch` `version.json`，GitHub Pages 原生支持静态文件服务，可直接生效。

## 数据说明

- 数据主要来自各高校官方教师主页、官方新闻与公开学术资料。
- 邮箱 / 电话以官方来源为准；无法获取时回退至院系官方联系方式，并在简介中标注。
- 每日 08:00 自动任务会增量核查人事变动、联系方式变更与新成果。
